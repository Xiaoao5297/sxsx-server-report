# Sxsx 服务器 · 举报与建议

本仓库是 **Sxsx Minecraft 服务器** 的对外工单入口，只做一件事：**接收举报与建议**。

## 怎么提交

点击上方 **Issues → New issue**，选择对应模板：

| 模板 | 用途 |
| --- | --- |
| 🚨 违规举报 | 作弊、外挂、恶意破坏、刷屏辱骂、诈骗、利用漏洞、管理滥用等 |
| 💡 建议 / 意见 | 玩法、活动、插件功能、规则与管理方式的改进建议 |

请**不要**在本仓库提交空白 issue，也不要在此讨论与服务器无关的话题。空白 issue 已关闭。

## 举报前请确认

- 尽量**当场取证**：截图、录屏、聊天记录、坐标与时间。证据越完整，处理越快。
- 写明**玩家 ID、发生时间、所在子服/地图**。重名或昵称相近时请附上 UUID 或正版 ID。
- **图片请直接拖进 issue 正文上传**，不要只发网盘链接（链接可能失效或需要登录）。
- 一次 issue 只报一件事，方便跟踪。

## 处理流程

1. 提交后 issue 会自动带上 `待处理` 标签。
2. 管理组查看证据 → 标记 `处理中`。
3. 处理完毕 → 标记 `已完成`，并在 issue 中回复处理结果。
4. 证据不足或不属于受理范围的 → `不予受理`，会说明原因。

处理时限一般为 **48 小时内首次回应**，复杂情况可能延长。请勿重复开新 issue 催单，直接在原 issue 下补充信息即可。

## 请勿发布

- 他人的真实姓名、住址、手机号、身份证、社交账号等隐私信息
- 密码、邮箱验证码、支付信息
- 与本服务器无关的广告、引流、政治与色情内容

**本仓库是公开的，所有内容任何人可见。** 涉及隐私或需要保密的举报，请通过服务器内的私聊渠道联系管理组，不要发在这里。

## 说明

- 恶意举报、伪造证据、刷屏骚扰会按服务器规则处理，包括但不限于封禁。
- 管理组对举报结果拥有最终解释权，但会在 issue 中给出理由。
- 本仓库不存放服务端代码、配置或数据，仅有本说明与 issue 模板。
